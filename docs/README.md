# LuaModQuickAPI 内容开发指南

按**推荐学习顺序**排列。每章都是「说明 + 示例 + 注意事项」，可以按顺序读，也可以直接跳到需要的章节。

| 顺序 | 章节 | 内容 |
|---|---|---|
| 1 | [合成](01-recipes.md) | 物品配方、独立配方、材料/合成站、生效时机 |
| 2 | [物品](02-items.md) | 注册物品、字段、语言、使用回调、发射弹幕、动画 |
| 3 | [弹幕](03-projectiles.md) | 注册弹幕、AI 与位移、追踪、命中/撞墙/销毁回调 |
| 4 | [Buff](04-buffs.md) | 增益/减益、每帧效果、挂上/移除、存档与规则 |
| 5 | [NPC](05-npcs.md) | 注册/生成、属性、AI 位移、掉落、Boss（实验性） |

## 建议的阅读路线

1. 先用 [合成](01-recipes.md) 熟悉「材料 / 结果 / 合成站」；
2. 用 [物品](02-items.md) 做一个能拿在手里、能用的东西；
3. 需要远程/特效时看 [弹幕](03-projectiles.md)；
4. 需要持续效果时看 [Buff](04-buffs.md)；
5. 需要生物/Boss 时看 [NPC](05-npcs.md)（实验性，先做小规模验证）。

> 所有示例都默认已经 `require("quickapi")`。基础 API（字段、方法、钩子）见
> [项目 README](../README.md)。
